# 3D car model

`car.glb` is the Spectral GT RS detailed sports-car model by JaronKBragg7337. The author dedicates the original model to the public domain under CC0 1.0 Universal. The model is an independent, non-branded sports coupe; it is not a BMW or an official BMW M4 Competition model.

The loader recentres the meter-scale car, places its lowest point on the studio floor, fits its longest horizontal dimension to approximately 5.8 scene units, and rotates the model's documented +X-forward axis onto the website's +Z-forward axis. The model's named exterior paint is changed to metallic sky blue; glass, wheels, tyres, lights, brakes, and interior materials are left unchanged. The existing ScrollTrigger camera journey displays the model throughout all nine chapters.
